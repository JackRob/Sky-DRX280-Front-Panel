# Panel control reference

These files describe generic panel button-mask calibration and status-channel discovery. They are preserved separately from any computer, enclosure, or external power-control integration.

UF2 images in the public archive are diagnostic/reference artifacts for panel communication and LED discovery. Check the exact Pico variant, level shifter, voltage rails, pull-ups and panel revision before flashing or wiring anything. Adapt the information for your own project.
